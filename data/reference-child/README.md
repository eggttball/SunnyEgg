# Local reference photos

Place a few clear JPG, JPEG, PNG, or WebP reference photos in this directory. They are used only by the local recognition process and are not served by the gallery. The directory contents are ignored by Git.

Run recognition from the project root after installing the optional Python dependencies and adding the local models described in `data/models/README.md`:

```bash
.venv/bin/python scripts/recognize.py
```
